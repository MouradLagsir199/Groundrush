# Groundrush

Skateboarding game concepts and the Museumplein skatepark asset.

- [Museumplein Blender asset](Blender/Museumplein/README.md): editable high-detail model, packed textures, comparison views and validation tools.
- [Game concept](CONCEPT.md)
- `Gameplay/`: gameplay and interface concepts.
- `Museumplein/` and `Misha/`: local reference collections, preserved on the authoring computer and excluded from Git. The top-view reference used for review is included with the model.

## Get the model

Install Git LFS before cloning, then run `git lfs pull`. Open `Blender/Museumplein/museumplein.blend` in Blender 5.2 or newer. The model is an editable source asset, not a game-optimized mesh.

Historical intermediate exports, temporary renders, caches and superseded incremental scripts were removed from the current tree. Git history is preserved.
